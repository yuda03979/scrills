# examples

A live project layer: `cd` anywhere under this folder and `scrills list` finds `.scrills/` here.

- `subagent` — hand work to fresh `claude -p` sessions: `run`, parallel `map`/`amap`, named sessions that survive between calls (`--resume`/`--fork-session`), structured answers via a JSON Schema, and a spend ledger with cheap defaults (sonnet, `--safe-mode`, a per-call budget). Shows: sync functions on threads with `async` twins, state carried across one-shot calls, metadata-only records.
- `media` — navigate a document before reading it: `info`, `outline`, `search`, then `text` of only the pages that matter, all cached by content hash. Pages with no text layer can be read by Claude (`vision=True`, capped at $1 per call by default). Shows: one scrill calling another (`from scrills import subagent`), lazy third-party imports with an actionable message, the PEP 723 block, paid-for results cached only when verified.
- `nudge` — get the user's attention, or their answer: `ask` shows a dialog and returns what they type; `start` keeps nudging until stopped — spoken when they're away, a notification when they're at the computer. Shows: a detached background process with per-nudger ids and scoped stop, liveness by a kernel lock the process holds (so a stale card can never make stop signal a stranger), messages kept out of argv, presence detection.
- `audit` — review a scrill before trusting it: a sandboxed, read-only Claude session reads the whole folder and returns `ok`/`caution`/`danger`, cached by content hash; `scrills run audit x && scrills run x` gates on a clean review of x's own folder, and the verdict lists the scrills x imports with their verdicts. Shows: composition on subagent, a structured verdict, exit codes as the program interface.
- `harness_config` — point a harness at scrills, from a scrill: for Claude Code, `apply` links `~/.claude/skills/scrills` to this install and adds `Bash(scrills:*)` to the permission allowlist, so sessions discover the manual and run scrills unprompted; `status` reports the wiring, `undo` removes exactly what apply added; settings.json is merged, never replaced. Shows: harness wiring as an example scrill instead of core machinery, `SCRILLS_CLI` as how a run finds its own install, `EXITS` naming a status exit.
